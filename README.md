# MetroCount · 上海地铁计价系统

基于 Django + SQLite 的上海地铁票价查询系统。内置**全网拓扑线路图**（仿百度地图网页版绘制），支持面板选站与全屏地图点站选站、最短路径计费、换乘方案、机场线/磁悬浮备选与可视化高亮，并集成票价表、常用路线/最近查询、起终点互换、分享链接与顶部实时时钟等实用功能。

## 功能特性

- **双页架构**：
  - **首页 `/`**：左右分栏，左侧为固定线路图（仅展示路线高亮，不响应点站），右侧为搜索/起终点下拉选择/票价结果面板；顶部有"全屏选站"按钮跳转全屏页。
  - **全屏选站页 `/map/`**：整张地铁拓扑图铺满视口，直接点击站点选起终点；选完右下角浮动卡片显示票价/路线/备选方案，不选时自动收起为蓝色悬浮小球（类豆包助手球），点击展开。
- **整网线路图**：21 条运营线路折线 + 532 个站点记录，按百度地图网页版拓扑布局重绘（`shmetro-map.svg` 抽为 `_map_svg.html` 共享片段，两页 include 同一份）。**固定大小不可缩放**，初始定位人民广场市中心，鼠标按住拖拽即可上下左右平移看郊区；"回中心"按钮一键回到市中心。
- **点击选站（全屏页）**：在地图上点击站点，第一次设为起点、第二次设为终点，第三次自动重置为新起点，点击非站点位置清空；选中站点橙色/蓝色圈标记，路线红色粗线高亮。拖拽超过 4px 不会误触选站。
- **票价查询**：起点 → 终点最短里程计费，显示票价、里程、预计时间、换乘次数与分段乘坐方案；乘坐方案按线路分段着色，换乘站白环高亮，方案外路径虚化。
- **机场线备选**：涉及机场的行程，折叠提供"市域机场线"更快备选（默认不展开）；**仅机场线站点**（景洪路/三林南/康桥东/上海国际旅游度假区）作为起终点时机场线作为主方案。
- **磁悬浮备选**：涉及浦东机场方向的行程，折叠提供"磁悬浮（龙阳路—浦东机场）"更快备选，按地铁+磁悬浮分段计价（磁悬浮 50 元）。
- **二级选择**：首页起点/终点按"线路 → 站点"二级目录选择，换乘站注明可换乘线路；附站名搜索。全屏页支持 URL 参数 `?origin=<id>&destination=<id>` 预选。
- **票价表视图**：结果区"行程票价 / 票价表"双 Tab；票价表以起点为中心列出全网可达站点（站名 / 票价 / 里程 / 线路四列），表头点击排序（线路按线路号数字排序，非数字线路排最后），点击行直接设为终点。
- **常用路线 / 最近查询**：localStorage 本地保存（两页共享同一份数据）；首页工具栏"常用 / 最近"chips 一键恢复，全屏页顶栏"常用 / 最近"下拉同样可用；**最近查询最多保留 6 条**（超出按时间移除最早的），**常用路线最多 10 条**、可点 × 手动取消收藏。
- **起终点互换**：首页工具栏"⇄ 互换"与全屏页浮动卡"⇄ 互换"，一键交换起终点并重新查询。
- **复制分享链接**：结果卡/浮动卡"复制链接"生成 `/map/?origin=<id>&destination=<id>` 分享地址（优先 Clipboard API，降级 `execCommand`）。
- **顶部实时时钟**：首页右上角实时显示"2026年10月12日 周一 11:00:21"格式，每秒跳动（等宽数字防抖动）。顶部仅保留品牌与时钟（已移除导航链接与图标），黑边下方为红/绿/黄/蓝四色地铁主题渐变线。
- **安全加固**：API 参数校验、前端输出转义、路径回溯防死循环、DB 查询缓存、生产模式安全头。

## 技术栈

- 后端：Django 4.2 + SQLite
- 前端：原生 HTML / CSS / JavaScript，内联 SVG 地图
- 数据：532 个站点记录 / 22 条线路记录（21 条运营线 + 虚拟换乘线）/ 1320 条边（含 290 条同站换乘边）/ 实测站间距 / 官方票价规则

## 启动运行

```powershell
cd D:\metrocount
.\.venv\Scripts\python.exe manage.py runserver 127.0.0.1:8000 --noreload
```

- 首页：<http://127.0.0.1:8000/>
- 全屏选站：<http://127.0.0.1:8000/map/>

> 注意：修改 `templates/`、`subway/views.py` 后需重启服务器；修改静态文件后需同步更新模板中对应的 `?v=` 缓存版本号。

## 票价规则

- **普通计价**：按最短乘坐里程计费，6 km 以内 3 元，超出部分每 10 km 加 1 元（`3 + ceil((km - 6) / 10)`）。
- **市域机场线**：7 站（虹桥2号航站楼 — 浦东1号2号航站楼）按官方站间票价表计价（4/7/9/11/14/15/17/20/24/26 元）；跨线行程按"机场线段查表 + 普通段连续计价"合并计算，最低 4 元。
- **磁悬浮**：龙阳路—浦东机场单程 50 元，约 8 分钟；作为机场方向行程的**折叠备选**（默认不展开），跨线行程按"普通段计价 + 磁悬浮 50 元"计算。
- **同站换乘**：同一物理站点不同线路无实际乘车，票价按 0 元处理。
- **路径规划**：以乘坐里程为第一权重求最短路径计价，以时间为第二权重求最快方案用于展示换乘信息；换乘步行惩罚中途 8 分钟，起点同站组 0 分钟、终点同站组 3 分钟；机场线/磁悬浮备选各自独立计算，仅当快于主方案时展示。

## 地图再生成

修改线路颜色、站名字号、站点尺寸、标签布局等视觉参数后：

```powershell
.\.venv\Scripts\python.exe gen_baidu_map.py   # 重新生成 static/subway/maps/shmetro-map.svg
.\.venv\Scripts\python.exe inline_svg.py      # 重新内联进 templates/subway/_map_svg.html
```

两页（首页 `/` 与全屏页 `/map/`）通过 `{% include 'subway/_map_svg.html' %}` 共享同一份 SVG，改图后无需分别处理。

## 数据来源

- 线路走向与站点位置：百度地图地铁线路图（`map.baidu.com/subways`）SVG 数据
- 站点间实际距离：上海地铁官方站间距（GitHub `ljy1005/shmetro`）
- 票价规则：上海地铁官网票价试行方案；磁悬浮票价/时刻表来自官方公开信息
- 首末班车时刻表：上海地铁官网（`https://service.shmetro.com/hcskb/index.htm?line=<线路>`，按线路分页；移动版每站时刻见 `m.shmetro.com/workspace/shmetrotest/view_lnfltime.aspx?ln=<线路>`）
- 行车间隔：上海地铁官网各线"工作日/周末 × 高峰/平峰"平均发车间隔表

## 规划中 / 已知限制

- **地图缩放**：地图为固定大小（不可缩放），按住拖拽平移 + "回中心"按钮；缩放功能暂未实现。
- **时刻表联动（预计到达 / 末班车提醒）**：方案已确认（前端实时时钟 + 官网首末班车与行车间隔数据 → 估算"预计到达时刻"、逐段检查末班车），尚未开工。注意：上海地铁无公开的逐班次实时时刻 API，结果按官方首末班时间 + 平均间隔**估算**，为估算级精度，非官方精确班次。
- **多方案对比**（少换乘/直达优先）、**累计优惠计费**（月消费满 100 元 9 折、满 150 元 9.5 折）、**运营状态/临时停运提示**、**公交/步行接驳**、**移动端适配**、**英文界面**：均为待办想法。
